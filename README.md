# ChordKeeper

O ChordKeeper é um sistema de gestão de cifras, onde você pode salvar as cifras de suas músicas via texto ou PDF, mantendo como um repostório de seu repertório, além de transpor suas cifras e também criar setlists para que você possa tocar em seus shows, com a possibilidade de gerar um PDF agrupado com todas as suas cifras.

### Funcionalidades
- [x] Salvar cifra em texto
- [x] Salvar cifra em PDF
- [x] Transpor cifra salvo em texto
- [ ] Leitura de cifra em PDF e salvar em texto
- [x] Montar setlist
- [x] Baixar cifra individual em PDF
- [x] Baixar cifras compiladas do setlist
- [ ] Compartilhar biblioteca entre usuários
- [ ] Compartilhar setlist por link público ou QR Code
